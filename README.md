# Cloud Infrastructure Platform

An end-to-end cloud infrastructure and platform engineering project built
to demonstrate practical skills in Python, Docker, Kubernetes, Terraform,
AWS, CI/CD, monitoring, and infrastructure automation.

## Project Goals

- Build and test a Python REST API.
- Containerize applications using Docker.
- Deploy and manage workloads on Kubernetes.
- Provision cloud infrastructure using Terraform.
- Deploy workloads to AWS EKS.
- Automate build and deployment workflows.
- Implement monitoring, logging, and reliability practices.
- Apply cloud security and infrastructure best practices.

## Technology Stack

| Area | Technologies |
|---|---|
| Application | Python, FastAPI |
| Testing | pytest, Ruff |
| Containers | Docker, Docker Compose |
| Orchestration | Kubernetes, Helm |
| Infrastructure as Code | Terraform |
| Cloud | AWS, later Azure |
| CI/CD | Jenkins, GitHub Actions |
| Monitoring | Prometheus, Grafana, CloudWatch |
| Version Control | Git, GitHub |

## Architecture

The architecture will evolve throughout the project, starting with
a local Python application and progressing toward a cloud-native
deployment on AWS EKS.

## Project Roadmap

1. Python application development and testing.
2. Docker containerization and PostgreSQL integration.
3. Local Kubernetes deployment.
4. Terraform and AWS networking foundations.
5. AWS EKS and ECR deployment.
6. CI/CD automation.
7. Monitoring, observability, and reliability.
8. Security improvements and Azure extension.

## Learning Approach

Each phase includes architecture explanations, implementation,
troubleshooting exercises, and interview preparation.
